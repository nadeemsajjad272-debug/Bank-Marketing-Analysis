# 📊 Bank Marketing Campaign Optimization

## 📌 Project Overview
This project analyzes a bank's telemarketing campaign to improve conversion rates and maximize profit using SQL and Excel.

## 🎯 Objectives
- Identify high-value customer segments
- Optimize campaign strategy
- Maximize profit under budget constraints

## 🛠 Tools Used
- MySQL (Data analysis)
- Microsoft Excel (Dashboard & Simulation)

## 📈 Key Insights
- Optimal contact frequency: 1–3 calls
- High balance customers have higher conversion rates
- Targeted campaigns increase ROI significantly (up to 474%)

## 💰 Business Impact
- Base conversion rate: 11.7%
- Targeted conversion rate: 28.7%
- Profit improvement: 3.5x

## 🚀 Conclusion
Data-driven targeting significantly improves campaign efficiency and profitability compared to mass marketing.
